# GreenLink Melbourne — A1.2 Basic Application (Version 1)

GreenLink Melbourne is a Vue 3 web application for the Urban greening, tree-planting & biodiversity topic.

## Business Requirements covered

### Category A
- BR (A.1): VueJS 3 with Composition API
- BR (A.2): Responsive layout using Bootstrap 5 and responsive CSS

### Category B
- BR (B.1): User input validation:
  - required name
  - minimum name length
  - email format
  - participant number range
  - agreement checkbox
- BR (B.2): Dynamic data:
  - events are stored in JavaScript reactive state
  - search and filters update the displayed event cards dynamically
  - booking data is persisted using Local Storage
  - available places are updated after a booking

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
